# Task 3 – List Rendering & Conditional Rendering

## Project Overview
A React application demonstrating List Rendering and Conditional Rendering concepts.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Features
- Displays five user profiles dynamically.
- Uses the map() method to render user data.
- Uses unique keys for each user.
- Implements Login and Logout functionality.
- Uses useState() to manage login status.
- Uses the ternary operator for conditional rendering.
- Responsive user management dashboard.

## Components
- App – Main application component.
- Login – Login interface.
- Home – Dashboard interface.
- UserList – Displays user information.

## How to Run

1. Clone this repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

## Concepts Implemented
- List Rendering
- map()
- React Props
- useState()
- Conditional Rendering
- Ternary Operator
